# DailyScope - News Website

A modern and responsive news website with category filtering, live search, dynamic navbar, and smooth user interactions.

## Features
- **Live Keyword Search:** Instant search functionality across news cards.
- **Category Filtering:** Dynamic filtering by categories like Technology, Business, etc.
- **Responsive Navigation:** Interactive hamburger menu for mobile devices.
- **Smooth UI:** Integrated scroll effects and active link indicators.

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
